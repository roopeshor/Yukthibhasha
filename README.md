# Yukthibhasha

Digitised version of Yukthibhasha in Typst. Pulled from https://ml.wikisource.org/wiki/സൂചിക:Yukthibhasha1948.pdf
This version tries to fix typos from original text.

This requires Santhosh Thottingal's patch of Typst for better hyphenation. 
https://github.com/santhoshtr/typst/tree/hyphenation-word-filter-fix . But CeTZ requires Typst 0.15, so figures needs to be compiled to pdf in `figs/` directory and included as pdf in typst files.

However upstream Typst 0.15.1 works fine, without better hyphenation.
